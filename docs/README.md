## 졸업논문

- **제목:** UWB를 이용한 스마트 카트
- **영문 제목:** Smart Cart System Using UWB-Based Distance Measurement
- **소속:** 한국공학대학교 전자공학부
- **참여자:** 박성훈 · 이지현 · 정상현 · 최어진
- **구분:** 2026년도 졸업논문

[졸업논문 PDF 읽기](UWB%EB%A5%BC%20%EC%9D%B4%EC%9A%A9%ED%95%9C%20%EC%8A%A4%EB%A7%88%ED%8A%B8%20%EC%B9%B4%ED%8A%B8_%EB%B0%95%EC%84%B1%ED%9B%88%2C%20%EC%9D%B4%EC%A7%80%ED%98%84%2C%20%EC%A0%95%EC%83%81%ED%98%84%2C%20%EC%B5%9C%EC%96%B4%EC%A7%84.pdf)

논문은 개발 배경, 하드웨어 구성, 통신 프로토콜, 거리 처리와 주행 알고리즘, 실험 결과를 다룬다. 저장소의 소프트웨어는 논문의 구현 내용을 펌웨어·중앙 제어·모바일 앱으로 나누어 정리했다.
