# Raspberry Pi · 스마트 카트 제어

[프로젝트 소개로 돌아가기](../README.md)

[UWB_smartcart_main.py](UWB_smartcart_main.py)는 두 UWB 앵커의 거리 수신, 필터링·보정, 좌우 모터 제어, 초음파 장애물 회피와 Android 앱 통신을 담당한다. 하드웨어 제어와 TCP 서버를 각각 스레드로 실행하고 큐로 명령과 상태를 교환한다.

## 실행 환경

- Raspberry Pi와 GPIO를 사용할 수 있는 Linux/Python 3 환경.
- Python 패키지: `numpy`, `pyserial`, `RPi.GPIO`.
- USB 시리얼로 연결된 앵커 2개, 초음파 센서 3개, 좌우 모터 드라이버 배선.

Python 환경에 제어 프로그램의 의존성을 설치한다.

```bash
python3 -m pip install numpy pyserial RPi.GPIO
```

OS가 시스템 Python 패키지 설치를 제한하면 해당 OS의 패키지 관리 방식이나 가상환경을 사용한다.

## 시리얼 및 네트워크 설정

| 항목 | 기본값 |
| --- | --- |
| 앵커 A 포트 | `/dev/esp_A` |
| 앵커 B 포트 | `/dev/esp_B` |
| 시리얼 속도 / 타임아웃 | 115200 baud / 1초 |
| TCP 바인딩 | 모든 인터페이스 (`HOST = ''`) |
| TCP 포트 | `5000` |
| 네트워크 루프 대기 | `DELAY = 0.05`초 |

`/dev/esp_A`, `/dev/esp_B`는 준비되어 있어야 하는 장치 경로이다. 실제 장치에 맞는 별칭을 만들거나 코드의 `serial.Serial(...)` 경로를 수정한다. 앱과 Raspberry Pi는 서로 접근 가능한 네트워크에 연결하고, 앱의 서버 IP를 Raspberry Pi 주소로 변경한다.

## GPIO 연결

코드는 `GPIO.BCM` 번호 체계를 사용한다.

| 장치 | 신호 | BCM GPIO |
| --- | --- | --- |
| 왼쪽 초음파 | TRIG / ECHO | 27 / 17 |
| 중앙 초음파 | TRIG / ECHO | 20 / 21 |
| 오른쪽 초음파 | TRIG / ECHO | 25 / 22 |
| 왼쪽 모터 | IN1 / IN2 / ENA | 24 / 23 / 18 |
| 오른쪽 모터 | IN3 / IN4 / ENB | 6 / 5 / 13 |

모터 PWM 주파수는 100 Hz이다. 논문의 HC-SR04 배선은 ECHO 전압을 분압해 Raspberry Pi에 입력하는 구성이다.

## 거리 처리와 주행 설정

1. 각 시리얼 버퍼의 마지막 줄에서 거리를 읽는다.
2. 최근 5개 측정값의 이동평균을 구한다. 직전 수용값과 차이가 0.3 m 이상이면 이력을 초기화하고 새 값을 사용한다.
3. 앵커별 3차 보정식을 적용한다. A는 입력 거리 1.5 m 이하, B는 3.0 m 이하에 적용하며, 보정 결과의 하한은 0.5 m이다.
4. 보정된 두 거리로 중심 거리를 계산한다. 조향에는 **보정 전 이동평균 거리 차이**를 사용한다.

중심 거리 계산식은 `r = sqrt(max(0, (dA² + dB²) / 2 - L²))`이다. 여기서 코드의 `L_ANCHOR = 0.21`은 계산 함수 기준 **앵커 간격의 절반**이며, 전체 간격은 0.42 m이다.

| 항목 | 설정값 |
| --- | --- |
| 근접 정지 | 중심 거리 0.6 m 미만 |
| 속도 단계 경계 | 0.6 m, 2.0 m |
| 기본 PWM 듀티 | LOW 35 / MID 50 / HIGH 70 (%) |
| 조향 데드밴드 / 비례 계수 | 0.15 m / `Kp = 70.0` |
| 장애물 감지 | 50 cm 미만, 동일 센서에서 5회 연속 감지 |
| 장애물 재확인 전 대기 | 1.5초 |

위 값은 실물 배치 및 실험에 사용된 코드 설정이며, 실제 이동 속도(m/s)를 의미하지 않습니다.

## 앱 통신

앱은 줄바꿈을 붙인 문자열 명령을 보낸다.

| 명령 | 동작 |
| --- | --- |
| `START` | 추종 활성화 |
| `STOP` | 추종 비활성화 |
| `RESUME` | 대기 상태 해제 및 추종 비활성화. 재추종은 `START` 필요 |

서버의 상태 메시지도 줄바꿈으로 끝난다.

```text
DIST:1.23 MODE:TRACKING
```

`DIST`는 중심 거리(m)이며, 초기 메시지는 `DIST:--- MODE:POWERON`이다.

| 주요 MODE | 의미 |
| --- | --- |
| `POWERON` | 하드웨어 스레드 시작 |
| `WAITING` | 추종 시작 전 또는 정지 상태 |
| `TRACKING` | 사용자 추종 |
| `PROXIMITY_STOP` | 사용자 근접 정지 |
| `WAITING_FOR_RESUME` | 회피 중 공간을 확보하지 못해 대기 |
| `TRACKING_FAIL` | 코드의 거리 읽기 실패 조건 도달 |
| `AVOID_*` | 장애물 감지·후진·회전·직진 등 회피 단계 |

## 실행

저장소 루트에서 실행한다.

```bash
python3 controller/UWB_smartcart_main.py
```

시리얼과 GPIO 초기화 후 TCP 서버가 대기한다. 앱을 연결해 거리 표시를 확인하고 추종을 시작한다. `Ctrl+C`로 종료하면 종료 이벤트를 설정하고 스레드, 모터 PWM, 시리얼 및 GPIO를 정리하도록 구성되어 있다.
