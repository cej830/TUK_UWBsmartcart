# ESP32 · UWB 거리 측정 펌웨어

[프로젝트 소개로 돌아가기](../README.md)

ESP32와 DWM1000을 이용해 사용자 태그와 카트의 두 앵커 사이 거리를 측정한다. 앵커는 측정 결과를 시리얼로 출력하고, 태그는 앵커 A·B를 번갈아 호출한다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| [앵커A.c++](앵커A.c++) | 앵커 A의 거리 측정 응답 및 시리얼 출력 |
| [앵커B.c++](앵커B.c++) | 앵커 B의 거리 측정 응답 및 시리얼 출력 |
| [태그.c++](태그.c++) | 두 앵커에 순차적으로 측정 요청, 거리·방향 LCD 표시 |

## 개발 환경과 의존성

- Arduino 기반 ESP32 개발 환경.
- UWB 라이브러리: [arduino-dw1000-ng](https://github.com/F-Army/arduino-dw1000-ng) — 기존 프로젝트에서 사용하는 `DW1000Ng` 계열 헤더.
- 태그 LCD: `hd44780` 라이브러리의 `hd44780_I2Cexp` 클래스와 `Wire`.

펌웨어는 태그와 두 앵커의 역할에 따라 `.c++` 파일로 구분했다.

## 핀 설정

세 보드의 UWB 핀 상수는 동일하다. 아래 번호는 ESP32 GPIO 번호이다.

| 신호 | GPIO |
| --- | --- |
| SPI SCK | 18 |
| SPI MOSI | 23 |
| SPI MISO | 19 |
| SPI SS / CS | 4 |
| DWM1000 RST | 15 |
| DWM1000 IRQ | 17 |
| 태그 LCD SDA | 27 |
| 태그 LCD SCL | 26 |

태그의 LCD 초기화 크기는 16 × 2이다. SPI 핀 상수의 선언과 실제 보드의 SPI 기본 핀 구성이 일치하는지도 확인한다.

## 통신 설정

| 항목 | 설정값 |
| --- | --- |
| 시리얼 속도 | 115200 baud |
| UWB 채널 | Channel 5 |
| 데이터 전송률 | 850 kbps |
| PRF | 16 MHz |
| 프리앰블 | 길이 256, 코드 3 |
| 태그가 호출하는 앵커 주소 | `1`, `2` |
| 안테나 지연 | 앵커 `16530`, 태그 `16436` |

거리 측정 메시지는 `POLL → POLL_ACK → RANGE → RANGE_REPORT` 순서로 교환한다. 앵커는 타임스탬프를 이용한 비대칭 양방향 거리 계산과 라이브러리의 거리 바이어스 보정을 수행한다.

앵커의 정상 시리얼 출력 예시:

```text
R: 1.2345 @ 123456
```

첫 번째 값은 거리(m), `@` 뒤는 ESP32의 `millis()` 값이다. 코드에는 측정 실패 시 `R: 9999 @ ...`, 비활성 리셋 시 `R: nosig @ ...`를 출력하는 경로도 있다.

## 소프트웨어 구성

태그는 측정 요청과 타임스탬프 전송을 담당하고, 앵커는 거리 계산 결과를 태그와 Raspberry Pi에 전달한다. 태그의 LCD 출력은 현장 거리·방향 확인에 사용하며, 카트 주행은 [중앙 제어 프로그램](../controller/README.md)에서 처리한다.

## 스케치 구성

보드별로 독립된 Arduino 스케치를 만들고 해당 `.c++` 소스를 `.ino`로 구성한다. ESP32 보드 환경과 DW1000Ng를 준비하고, 태그에는 LCD용 hd44780 라이브러리를 추가한다. 각 보드의 배선과 통신 설정을 맞춘 뒤 업로드한다.
